Finance Vision v21 — GitHub Pages PWA

1. Extract this ZIP.
2. Upload all files in this folder to the ROOT of your GitHub repository (not the ZIP alone).
3. GitHub repository > Settings > Pages > Deploy from a branch > main > /(root) > Save.
4. Open the GitHub Pages HTTPS URL on iPhone Safari. Tap Share > Add to Home Screen.
5. Data is stored locally in the browser on each device. Back up/export your finance data before clearing Safari website data, changing devices, or uninstalling the app. GitHub does not sync personal finance data.
