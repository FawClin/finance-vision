Finance AI PWA

Upload ALL files in this folder to the same GitHub Pages repository/folder:
- index.html
- manifest.json
- service-worker.js
- icon-192.png
- icon-512.png
- apple-touch-icon.png

GitHub Pages:
1. Create/open a repository (for example finance-ai).
2. Upload all six files to the repository root.
3. Settings -> Pages.
4. Deploy from branch: main, folder: /(root).
5. Open the published HTTPS URL in Safari on iPhone.
6. Share -> Add to Home Screen.

Important:
- Your Finance AI data is stored in that site's browser/localStorage.
- Installing as a PWA does not itself transfer data from an older HTML viewer/site.
- Once hosted under a stable HTTPS URL, keep using the same URL/repository so the local app data stays associated with that origin.
